Bindings view — design test

Problem with the current Advanced tab: rows are as wide as the window, every bind is a small text link far to the right, unbound is the invisible default state, and there is no column structure — so 31 actions read as an empty page. Three ways out, same tokens, same data.

A

Column grid

Overwatch parity: capped width, fixed Primary/Secondary/Options columns, filled cells with an EMPTY state, group rules, zebra rows, hover reset.

 open → B

Keycap cards

Uses the width instead of fighting it: action tiles in an auto-fill grid, real keycaps, hatched unbound tiles, categories in a left rail, summary strip on top.

 open → C

Keyboard first

Split view: action index left, live keyboard + mouse map right. Shows free keys, foreign binds, layer triggers and collisions at a glance; bind by clicking a key.
